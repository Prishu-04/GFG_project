Traffic Project Flow Map

How the files in Dynamic Urban Traffic Prediction hand data to each other, from the raw CSV to the pages you see in the browser. Every arrow below was traced from the code's imports and file reads and writes.

There are two separate models. The Predict page runs the scikit-learn classifier saved in artifacts/ by src/pipeline. The ten-model comparison on the Results page comes from src/deep_learning, which trains on a different file with a different split. The two paths share only the raw data, and the saved neural-network .pt files are never loaded by the app.

Run order

Run from the project root. Each command creates the files the next one needs.

  1. python src/data_processing/data_cleaning.pycreates data/processed/ (cleaned.csv, model_ready.csv, cleaning_report.json)
  2. python src/visualization/data_visualization.pycreates the 12 charts in reports/figures/eda/
  3. python -m src.pipeline.train_pipelinecreates artifacts/ (train.csv, test.csv, preprocessor.pkl, model.pkl) for the Predict page
  4. python -m src.deep_learning.baselinescreates metrics for persistence and gradient boosting
  5. python -m src.deep_learning.classicalcreates metrics for ridge, k-NN, decision tree and random forest
  6. python -m src.deep_learning.train --model allcreates metrics for MLP, LSTM, GRU and Transformer, plus models/deep_learning/*.pt
  7. python -m src.deep_learning.reportcreates model_comparison.csv/.md and the comparison charts
  8. python app/app.pyserves http://localhost:5000 with the Home, Predict and Results pages
